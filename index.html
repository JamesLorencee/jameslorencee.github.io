$ Whoami #

I’m a Cybersecurity Professional and Security Consultant with a strong passion for offensive security, vulnerability research, and understanding how real-world attacks work.

This blog is where I document what I learn, what I break, and what I discover while continuously sharpening my skills in cybersecurity.

$ What I Do #

My work and research primarily focus on identifying weaknesses before attackers can exploit them.

  • Vulnerability Assessment & Penetration Testing (VAPT)
  • Web Application Security
  • Network Penetration Testing
  • Active Directory Security
  • Wireless / Wi-Fi Security
  • Social Engineering & Human Attack Vectors
  • OSINT & Reconnaissance
  • Security Research & Vulnerability Discovery

⚔️ Offensive Security #

I’m particularly interested in offensive security and the mindset behind real-world adversaries.

My long-term goal is to become an exceptional Red Team Operator, capable of thinking beyond individual vulnerabilities and understanding how separate weaknesses can be chained together to achieve realistic attack objectives.

I’m constantly exploring:

  • Red Team methodologies
  • Exploitation and vulnerability research
  • Authentication and authorization weaknesses
  • Attack-chain development
  • Post-exploitation techniques
  • Adversary tradecraft
  • Internal network compromise
  • Active Directory attack paths
  • Detection evasion and operational security
